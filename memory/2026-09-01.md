2. **lemmalog Review 2026** (reviews, 7.8/10, body 1204 词) — JordyZomer/lemmalog 234★/17 forks（08-27 创建，5 天内），MIT，Rust。
   - 定位：LLM agent memory 的 Datalog 引擎 — "an agent's memory should be a deductive database"：base facts 在 LLM extraction boundary 断言，规则推导 closure/temporal projection/contradiction candidate/relevance diffusion，每个 fact 带 provenance 回溯到 source episode，每轮对话增量更新派生视图
   - 问题依据：context rot（Liu et al. arXiv:2307.03172 / Chroma 2025 / NVIDIA RULER arXiv:2404.06654，有效可靠上下文常只有 4k-32k tokens）；LongMemEval arXiv:2410.10813 — 知识更新/时间推理 frontier 模型掉 21-30%，因为现有 memory 系统没有 principled supersession model
   - 已实现（README status 表逐项 ✅）：runtime-parsed stratified Datalog（interpreter 非 proc-macro）、negation-as-absence、seminaive fixpoint + per-epoch delta、bi-temporal facts（valid_from/valid_to/asserted_at + now()）、semiring 注解（confidence product t-norm × provenance set union）、why() proof tree 带 cycle protection、scoped negative deltas、magic-sets ask_deep、BM25+entity/graph hybrid retrieval、entity resolution（star-shaped aliasing → canonical closure）、what_if 假设（byte-identical restore）、streaming change feed、4M facts 点查 ~100µs、differential testing 450 random programs vs naive oracle + parser fuzzing
   - 未来阶段（README 明示）：leapfrog triejoins、DBSP streaming deltas
   - MCP server：`cargo build --release --features mcp`，stdio JSON-RPC 12 tools，Claude Code/Kimi CLI 双支持，LEMMALOG_MCP_PATH env 持久化；line protocol `S --rel[conf]--> O`；grammar gotcha：裸大写词是变量，实体名必须加引号
   - 关键设计约束：LLM call 绝不放进 Datalog fixpoint（非单调且贵），靠 strict stratification + memoization 保持 LLM predicates 在 fixpoint 外
   - 工程故事：entity resolution 修了两个长期 bug（same-stratum dependents 未处理 → SCC-condensation；invalidation 早于 lower strata → 移到 evaluation 后），都由 differential harness 抓到
   - 诚实边界：LLM 仍是 extraction boundary（推理确定性 ≠ 阅读确定性）；Rust 构建是 developer-grade 安装；5 天新项目无社区无 release；skill 纪律（assert-as-you-verify / why before trusting）是作者工作流的固化
   - 角度：vs 向量库（只检索不推导）、property-graph memory（Zep/Graphiti/Mem0/GraphRAG 存事实但推理靠 LLM 重做）、text-to-SQL/Cypher（无安全终止保证）

3. **useagent Review 2026** (reviews, 7.7/10, body 1056 词) — useagenthq/useagent 151★/18 forks（08-29 创建，3 天内），AGPL-3.0，TypeScript/bun。
   - 定位：open-source AI coworker — 把已有 coding agents（Claude Code/Codex/OpenCode/Pi）变成有自己 cloud computer 的同事，交回 finished work（live websites/decks/spreadsheets/reports/tested PRs）而非答案
   - 三大设计主张：① engine is a plug — 一个 provider-neutral event contract，换引擎不丢 threads/artifacts/memory；② every run is an event log — Postgres 为 source of truth，重启存活、精确回放、可事后检查；③ credentials never enter the sandbox — 所有集成（knowledge/memory/skills/GitHub/web search/desktop control/artifact publishing）都是 gateway 的 typed tools
   - 沙箱：每 thread 一个隔离 Linux workstation（terminal/repos/browser/noVNC 可见桌面 + MP4 录制），Daytona（managed）与 CubeSandbox（self-hosted，数据本地）两个 provider 一个 contract
   - Human-in-the-loop：destructive tools 在 web/Slack approval card 暂停，恢复时给 one-shot argument-bound capability
   - Slack-native：mention-to-run、threaded replies、attachments、artifacts、approvals 全在 thread 里；native DOCX/XLSX/PPTX/PDF artifacts 带 revisioned editing
   - 自托管：bun + Postgres 16+ pgvector（stock 镜像不含！），7 个 monorepo workspace，deploy-app.sh 走 SSH 支持任意 Linux 云，含 Hetzner 参考 Terraform
   - 诚实边界：alpha（API/schema 可变，需 pin tag）；AGPL-3.0 对分发/服务化有 copyleft；3 天新项目无 release history；编排免费但底层 agent capacity 是用户已有订阅；control plane 是皇冠明珠 — 所有 connector token 都在那里，沦陷=全部沦陷
   - 角度：vs hosted agent 平台（第三方看代码持 key）、plain agent CLI（无沙箱无审批无 artifact pipeline）、DIY 编排（自己造 event log/gateway/sandbox contract）
