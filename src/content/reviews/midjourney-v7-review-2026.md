## New Features in V7

### Real-Time Generation
The killer feature. Type "a cyberpunk cat riding a hoverboard" and Midjourney updates the image as you type — character by character. You can watch your prompt transform into an image in real time. This makes brainstorming visual ideas infinitely faster.

### Native 4K Output
V7 generates natively at 4K resolution (3840×2160), upscalable to 8K. No more 1024×1024 defaults. This is a huge leap for commercial use — you can use V7 images directly in print without upscaling artifacts.

### Style Reference V2
Upload 1-5 reference images and Midjourney extracts a "style DNA" — colors, lighting, composition, texture, and brush stroke patterns. Apply this DNA to any prompt for consistent branding across hundreds of images.

### Multi-Subject Consistency
V7 maintains character consistency across different scenes and poses. Upload a character sheet, and Midjourney generates that same character in different environments, clothing, and actions.

## FAQ

**Q: Can I use Midjourney V7 images commercially?**
A: Yes, all plans include commercial usage rights. Pro plan includes a broader commercial license suitable for merchandise, publishing, and advertising.

**Q: How is V7 different from V6?**
A: V7's real-time generation, 4K native output, Style Reference V2, and multi-subject consistency are the main upgrades. V6 to V7 is a bigger leap than V5 to V6.

**Q: Is Midjourney V7 worth the price over DALL-E 4?**
A: For artistic and creative work: yes. For product photography, advertising, and brand work: DALL-E 4's prompt accuracy and text rendering may be more practical.

**Q: Does V7 support video generation?**
A: No, Midjourney remains image-only. For AI video, consider Runway Gen-3 or Pika 2.0.
