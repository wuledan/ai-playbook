## 工作流总览

```
选题 → 文案 → 语音 → 视频素材 → 剪辑 → 发布
 │       │       │        │        │      │
```

### 全流程示例 (10分钟视频)

1. **选题**: VidIQ 找到高搜索量关键词 → 决定做 "Best AI Tools 2026"
2. **文案**: ChatGPT 写脚本 → Claude 优化口语化 → 调整节奏
3. **配音**: ElevenLabs 选择 "Adam" 声音 → 导出 WAV
4. **素材**: Pexels 下载相关视频素材 + Runway Gen-4 生成 AI 演示画面
5. **剪辑**: CapCut 自动添加字幕 + AI 识别重点片段
6. **缩略图**: Canva 模板 + 醒目文字 + arrow icon
7. **发布**: VidIQ 优化标题/描述/Tags
