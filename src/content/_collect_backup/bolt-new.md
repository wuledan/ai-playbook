## 基本信息

| 项目 | 内容 |
|------|------|

| **官网** | https://bolt.new |
| **首次发布** | 2024年 |
| **核心技术** | WebContainers (浏览器内运行 Node.js) |
| **定位** | Prompt-to-full-stack-app |
| **商业模式** | Freemium (SaaS) |

### 核心功能列表

1. **Prompt-to-App** — 自然语言描述→全栈应用自动构建
2. **WebContainers** — 浏览器内运行真实 Node.js 服务器
3. **一键部署** — 集成 Netlify 部署
4. **多语言/框架** — React, Vue, Svelte, Next.js, Express 等
5. **数据库集成** — SQLite, PostgreSQL
6. **API 集成** — 内置 REST API 和第三方 API 支持
7. **版本控制** — Git 集成，PR 管理
8. **实时预览** — 编辑器内实时运行应用
9. **社区模板** — 预设项目模板
