### 核心功能列表

1. **Text-to-Image** — 文字到图像生成（核心功能）
2. **Image-to-Image** — 以图生图（垫图）
3. **Style Reference** — 参考图片风格生成
4. **Character Reference** — 角色一致性（新功能）
5. **Inpainting/Outpainting** — 局部重绘/扩展
6. **Vary (Subtle/Strong)** — 同 Prompt 变体生成
7. **Zoom Out** — 向外扩展视野
8. **Pan** — 平移扩展
9. **Remix** — 混合 Prompt 重生成
10. **Upscale** — 高清放大
11. **Web UI (Alpha)** — 浏览器界面替代 Discord
12. **API** — 开发者接口

## 用户评价摘要

### 正面评价（基于公开讨论总结）

1. "v7 的图像质量和细节大幅提升，接近照片级"
2. "角色一致性功能是 game changer，解决了一年来的 core pain point"
3. "艺术风格仍然是行业第一，抽象和概念设计无人能敌"

5. "参数控制（--ar, --s, --stylize 等）给了创作者极大的精细度"

### 负面评价

1. "必须通过 Discord 使用（除非用 Web UI alpha），学习曲线陡峭"
2. "v7 更耗 GPU 时间，同样的月费能生成的图片更少"
3. "实时渲染模式的卡通风格不太好控制"
4. "文字生成能力仍然弱（DALL-E 在这方面更强）"
5. "定价相对高，重度用户月费可达 $60-$120"

### 常见讨论点

- **v7 vs v6**: 质量明显提升但成本增加
- **Discord vs Web UI**: Web UI 体验是否足够替代？
- **vs DALL-E**: 艺术 vs 精准，哪个更重要？

## 实测体验（基于现有认知）

### 注册流程

| 步骤 | 耗时 | 难度 |
|------|------|------|
| 注册 Discord 账号（如未有） | ~2 min | ★☆☆ |
| 加入 Midjourney Discord 服务器 | ~30s | ★☆☆ |
| 订阅计划 | ~2 min | ★☆☆ |
| 在 #newbies 频道开始生成 | 即时 | ★★☆ (需学习指令) |

### v7 核心体验

1. **图像质量**: 整体提升明显，纹理更细腻、光影更自然
2. **角色一致性**: 同一角色不同场景的连续性大幅提升（之前是 Midjourney 最大短板）
3. **Prompt 理解**: 比以前更准确，但复杂场景控制仍需经验
4. **渲染速度**: v7 比 v6 慢（全场景更详细），GPU 消耗更高

### 输出质量

- **艺术性**: ⭐⭐⭐⭐⭐ (业界最佳，抽象概念/魔幻/科幻风格尤强)
- **写实度**: ⭐⭐⭐⭐ (v7 大幅提升，但仍有"AI 感")
- **控准性**: ⭐⭐⭐⭐ (角色一致性改进明显，复杂场景仍需微调)
- **文字生成**: ⭐⭐⭐ (不是首选工具)

### 速度/稳定性

- 图片生成: 45-90s (v7 慢于 v6)
- Upscale: 10-20s
- 稳定性: 很稳定，较少 downtime
