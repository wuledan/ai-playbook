## 场景推荐

| 任务 | 最佳工具 | 理由 |
|------|---------|------|
| 探索性数据分析 | ChatGPT | Python 沙盒 + 强大图表 + 自然语言交互 |
| 数据报告长文 | Claude | 长报告写作 + 分析+叙事一体 |
| 即时查询/小分析 | Gemini | 免费+快+Google生态 |
| 复杂 SQL 生成 | Claude | 理解 schema 上下文最强 |
| 教学/学习数据分析 | ChatGPT | 交互式 Python 执行+解释 |
