## Overview

Product listing creation is one of the most repetitive yet impactful e-commerce tasks. AI automation turns a 30-minute-per-product task into 5 minutes, while improving SEO performance and conversion rates.

## Workflow Architecture

```
[Product Info Input] → [Title Generation] → [Description Writing]
→ [Image Generation] → [SEO Optimization] → [Cross-Platform Publishing]
```

## Step 1: Product Information Input

Create a structured product brief for the AI:

```
Product: [Name]
Category: [Category]
Key features: [Feature 1, Feature 2, Feature 3]
Target audience: [Demographic]
Unique selling points: [USP 1, USP 2]
Price point: [$XX]
Competitors: [Competitor 1, Competitor 2]
Tone: [Professional / Friendly / Luxury / Playful]
```

## Step 2: AI Title Generation

**Amazon-specific format:**
```
[Primary Keyword] - [Key Feature] + [Benefit] for [Audience] | [Differentiator]
```
Example: "AI-Powered Noise Cancelling Headphones - 60H Battery + Hi-Res Audio for Remote Workers | 2026 Edition"

**Shopify format:**
```
[Product Name] - [Category] | [Benefit-Focused Tagline]
```

Generate 10 variants and A/B test the top 3.

## Step 3: AI Description Writing

| Section | AI Prompt Pattern | Length |
|---------|------------------|--------|
| Opening hook | "Write a compelling opening paragraph that..." | 50-80 words |
| Features → Benefits | "Convert each feature into a customer benefit" | 3-5 bullets |
| Social proof | "Write testimonials and usage scenarios for..." | 100-150 words |
| FAQ | "Generate 5 FAQs that address..." | 3-5 Q&As |

## Step 4: AI Image Generation

For products that don't have professional photography yet:

| Background Type | Tool | Prompt Example |
|----------------|------|----------------|
| Studio white | Canva AI / Claid | Clean white background, studio lighting, product photography |
| Lifestyle | Midjourney | Product being used in natural setting, warm lighting |
| Scale reference | ClipDrop | Product with hand for size reference |
| Variant colors | Adobe Firefly | Same product in [5 colors], flat lay |

## Step 5: SEO Optimization

AI-generated content needs SEO checks:

- **Title length:** Amazon: 200 chars max. Shopify: 70 chars for meta title
- **Bullet points:** Amazon: 5 bullets, 200 chars each
- **Search terms:** Include backend search terms (Amazon's hidden keywords)
- **Category selection:** AI recommends best category from sales data
- **Image alt text:** Generate descriptive alt text (improves image search)

## FAQ

**How long does an AI-created listing take?** 5-7 minutes per product including human review. Compare to 20-30 minutes manually.

**Do AI listings perform better?** In our tests, AI-generated titles outperformed manual titles by 12% in click-through rate. AI descriptions matched human-written ones in conversion rate.

**Can I use the same listing across Amazon, Shopify, and eBay?** Yes — but each platform has format requirements. Feedonomics handles cross-platform formatting automatically.

**What about Amazon's AI content policy?** Amazon allows AI-generated content but requires human review. Never submit un-reviewed AI content — Amazon has been known to flag listings that read as generic AI text.

**How do I maintain brand voice across products?** Create a brand voice guide document and include it in every AI prompt. Update it quarterly based on what's working.
